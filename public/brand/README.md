# Brand assets

- `logo-mark.png` — simbol logo (latar transparan), tampil di samping tulisan
  "JeniusAcademy" di navbar, footer, halaman login, sertifikat, dan gambar OG.
  Diatur di `siteConfig.logo.mark` (`src/config/site.ts`).
- Favicon: `src/app/icon.png` (256×256, transparan) dan `src/app/apple-icon.png`
  (180×180, latar putih untuk iOS).

Untuk memakai logo lengkap (simbol + tulisan dalam satu gambar), letakkan filenya
di sini lalu isi `siteConfig.logo.src`, mis. `"/brand/logo.svg"`.
